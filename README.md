🍲 Homemade Hub – Homemade Food Marketplace Platform

📌 Project Overview

Homemade Hub is an online platform that connects homemade food sellers with customers. It allows home cooks to showcase their homemade food products and enables customers to explore food items and place orders conveniently.

✨ Key Features

- User registration and login
- Browse homemade food products
- View food details and prices
- Connect home cooks with customers
- Convenient online food ordering
- User-friendly interface

🛠️ Technologies Used

- Programming Language: Java
- Backend Framework: Spring Boot
- Database: MySQL
- Frontend: HTML, CSS, and JavaScript (if implemented)

🎯 Project Objective

To provide a convenient digital marketplace for homemade food, support small-scale home-based food businesses, and help customers discover homemade meals.

🚀 Project Outcome

The project aims to simplify homemade food ordering and create opportunities for home cooks to reach more customers.

⚙️ Installation and Setup

1. Clone or download this repository.
2. Import the project into Eclipse as an existing Maven project.
3. Configure your MySQL database credentials in "application.properties".
4. Start the MySQL server.
5. Run the Spring Boot main application.
6. Open "http://localhost:8080" in your browser.
